# HistoTechOpen

**Open-science infrastructure for histological methodology.**

Histochemical technique — fixation, tissue handling, labelling, processing —
determines the quality of every downstream biological finding, yet it is
rarely studied with the rigour applied to the biology it enables.
HistoTechOpen treats histological procedure itself as a scientific object:
developing, validating, and openly disseminating the tools, protocols, and
datasets that make histology reproducible at any scale.

## What we build and release
- **KnowledgeManagr** — open-source R package implementing a plaintext,
  filesystem-native electronic lab notebook, built to make rigorous
  documentation practical in any lab.
- **Procedure Packs** — modular, version-controlled histological protocols
  with embedded metadata, released for reuse and benchmarking.
- Open reference datasets generated under fully documented, reproducible
  conditions.

## Why this matters for neurodegenerative disease research
Reliable, reproducible tissue-processing methodology underpins every
histological finding used to understand dementia and neurodegeneration —
from validating pathology markers to building trustworthy brain atlases.
HistoTechOpen exists to make that methodological foundation as rigorous,
transparent, and reusable as the biology it supports.
