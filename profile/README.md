## The Core Proposition

The quality and interpretability of histological data is determined at the
procedural level — fixation, tissue handling, labelling parameters, processing
conditions. HistoTechOpen exists to study and optimise that procedural layer
directly. Output like the image below is the standard we're building toward,
not the exception.

<!-- IMAGE: best synaptic/dendritic reconstruction, large -->

## The Three Pillars

Histological science divides into three pillars, all dependent on one core
workflow.

- **Histochemistry** — the discipline: chemical, biochemical, and molecular
  processes that inform and optimise the workflow
- **Histotechnology** — the engineering: tools and procedure implementations
  that execute the workflow
- **Histoarchitecture** — the knowledge: tissue structure derived from
  histochemistry

All three depend on the same core Histochemical Workflow.

## Activities

### 1. Documentation
Standards and metadata frameworks that must exist before procedure work can
be documented at all.

<!-- IMAGE: protocol/Rmd screenshot -->

### 2. Procedure Science
Using those standards to develop and mechanistically characterise
histochemical workflows.

Workflow stages: Provenance → Preserve → Access → Label → Stabilise

<!-- IMAGE: processing-sequence thumbnails -->

### 3. Open Reference Datasets
High-quality, ground-truth datasets collected using the refined procedures.

<!-- IMAGE: stain-type tile grid -->

### 4. Data Processing
Software that extracts understanding from that data.

Workflow stages: Image Formation Models → Image Processing Pipelines → Image Analysis Methods
